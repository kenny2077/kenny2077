## Planned AI Projects

### Local LLM

- 🏠 **local-llm-lab** - Reproducible local model workbench for quantized models, prompt experiments, eval runs, and hardware notes.
- 📦 **offline-rag-kit** - Local RAG starter kit with document parsing, embeddings, retrieval evaluation, and private inference.
- ⚡ **llm-bench-mini** - Lightweight benchmark suite for measuring latency, memory use, throughput, and output quality across local models.

### LLM Interpretability

- 🔬 **tiny-interp-lab** - Notebook-first experiments for activation patching, attention inspection, and logit-lens style analysis.
- 🧩 **sae-playground** - Sparse autoencoder training and visualization pipeline for small open-weight language models.
- 📊 **prompt-attribution-map** - Tooling to trace which prompt spans influence model outputs across multiple decoding settings.

### Agent Safety

- 🚦 **agent-safety-bench** - Sandboxed evaluation harness for tool-using agents, focused on escalation, autonomy, and recovery behavior.
- 🔐 **tool-policy-gate** - Policy layer for blocking, approving, and logging sensitive tool calls before an agent can execute them.
- 📒 **agent-audit-log** - Tamper-evident event log for agent decisions, tool calls, approvals, files touched, and external effects.
